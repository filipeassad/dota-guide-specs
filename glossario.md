# Glossário do Dota Guide

Termos usados no PRD, na constituição e nas specs. Na dúvida, vale o que está aqui.

## Pessoas e perfis

| Termo | Quem é |
| --- | --- |
| **Visitante** | Pessoa sem conta (ou sem login). Lê builds, comentários e notícias. |
| **Usuário** | Pessoa com conta e login. Cria builds, vota e comenta. |
| **Autor** | O usuário que criou uma build ou um comentário. Só ele edita ou exclui o que é seu. |
| **Admin** | Equipe do portal. Cadastra versões e notícias e modera conteúdo e usuários. |
| **E-mail confirmado** | Usuário que abriu o link de confirmação. Só ele cria builds, vota e comenta. |
| **Suspenso** | Usuário impedido pelo admin, por um período, de criar builds, votar e comentar. Ainda consegue entrar. |
| **Banido** | Usuário impedido pelo admin de entrar no portal. |
| **Conta excluída** | Conta apagada pelo próprio usuário. As builds dela continuam publicadas, sem dono. |

## Jogo

| Termo | Significado |
| --- | --- |
| **Versão (patch)** | Uma versão do Dota 2, identificada pelo número oficial (ex.: 7.37d). |
| **Versão atual** | A versão vigente no jogo. Marcada automaticamente ao fim da importação de uma versão nova; o admin pode trocar. Só existe uma por vez. |
| **Dados do jogo** | Heróis, habilidades, talentos, efeitos de Aghanim e itens de uma versão. Vêm de fonte externa (constituição, princípio II). |
| **Herói** | Personagem jogável. |
| **Habilidade (skill)** | Poder do herói que recebe pontos ao subir de nível. |
| **Ultimate** | Habilidade principal do herói, com regras próprias de nível. |
| **Talento** | Bônus escolhido em níveis fixos do herói. Em cada nível de talento há duas opções. |
| **Árvore de talentos** | O conjunto dos níveis de talento de um herói, com as duas opções de cada. Lida de baixo para cima: 10, 15, 20 e 25. |
| **Item** | Objeto comprado na loja do jogo. |
| **Item neutro (artefato)** | Item que não é comprado na loja e tem um tier (1 a 4). Fica numa seção própria da build. |
| **Bênção** | Encantamento de item neutro: bônus com valores por nível, escolhido à parte do artefato. No jogo, aparece com nomes como Vast (Grandeza). Fica na mesma seção dos itens neutros. |
| **Efeito de Aghanim** | O que Aghanim's Scepter ou Aghanim's Shard muda num herói específico. Varia por herói e por versão. |
| **Posição** | Função do herói no time: 1 (carry), 2 (mid), 3 (offlane), 4 (suporte) e 5 (hard suporte). |

## Builds

| Termo | Significado |
| --- | --- |
| **Build** | Guia de como jogar um herói numa versão: ordem de habilidades, grupos de itens, talentos e textos explicativos. |
| **Sequência de níveis** | O que o herói pega em cada nível: uma habilidade ou um talento. Exibida numa grade com uma linha por habilidade, uma linha de talentos e uma coluna por nível. |
| **Habilidade inata** | Habilidade que o herói já tem desde o início e que não recebe pontos. Aparece fora da grade. |
| **Grupo de itens** | Lista nomeada e ordenada de itens (ex.: "Early game"). O nome é livre. |
| **Justificativa** | Texto opcional do autor explicando um item ou a importância de uma habilidade. |
| **Rascunho** | Build salva mas não publicada. Só o autor vê. |
| **Publicada** | Build visível para todos. |
| **Desatualizada** | Build de uma versão anterior à versão atual. Continua visível, com aviso. |
| **Cópia para outra versão** | Nova build criada a partir de outra, já vinculada a uma versão diferente. A original não muda. |

## Comunidade

| Termo | Significado |
| --- | --- |
| **Voto** | Avaliação de um usuário sobre a build de outro autor. Um por usuário por build. |
| **Pontuação** | Número calculado a partir dos votos de uma build. É o que ordena o ranking. |
| **Ranking** | Ordem das builds pela pontuação, dentro de uma versão. |
| **Comentário** | Texto de um usuário numa build. Pode ser uma resposta a outro comentário. |
| **Denúncia** | Aviso de um usuário ao admin de que um comentário viola as regras. O admin exclui o comentário ou descarta a denúncia. |
| **Moderação** | Ação do admin de ocultar ou excluir conteúdo de usuários. |
| **Notícia** | Texto publicado pelo admin (ou gerado pela importação de versão nova) sobre o Dota 2. Rascunho, agendada ou publicada. |
| **Notícia agendada** | Notícia pronta que é publicada sozinha numa data e hora escolhidas pelo admin. |
| **Categoria** | Assunto da notícia (Patch, Torneio, Comunidade ou outra criada pelo admin). Cada notícia tem uma. |
